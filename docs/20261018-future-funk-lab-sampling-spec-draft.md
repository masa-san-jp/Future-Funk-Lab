# Future Funk Lab 仕様設計書の元ドキュメント

作成日: 2026-10-18
位置づけ: 仕様設計書の元になる整理資料。確定した内容と、未確定・未確認の内容を分けて記載する。
対象範囲: サンプリング、音声分離、グローバル設定(BPM)、チョップ、シーケンサー(一部仮置きあり)。

---

## 1. 製品概要

- 名称(仮): Future Funk Lab
- 目的: 音源を取り込み、範囲を切り出してチョップし、8トラックのステップシーケンサーで組んで書き出す、Future Funk向けのサンプラー兼シーケンサー。
- 形態(提案・未承認): ブラウザで動く単一HTMLのWebアプリ(Web Audio API)。DAWプラグインやデスクトップアプリは工数が大きいため、初版では見送る案。
- 元になった資料: 手書き図(サンプリング、チョップ、サンプラーの3画面)と、チャットでの行ごとの確認。
- UIモックアップ(サンプリングと音声分離の部分のみ): 非公開資料のためリンクは公開リポジトリに含めない

## 2. 機能構成と処理の流れ

```
元の音源(ファイル選択 または マイク録音)
  │
  ▼
グローバル設定のBPMに変換(タイムストレッチ)
  │
  ├─▶ サンプリング(範囲指定) ─▶ チョップ ─▶ シーケンサー(8トラック) ─▶ 書き出し
  │
  └─▶ 音声分離(オプション) ─▶ ボーカル/ベースを書き出し(チョップへは引き継がない)
```

| 機能 | 状態 |
|---|---|
| グローバル設定(BPM) | 確定 |
| サンプリング | 確定(一部に仮置きあり。5節) |
| 音声分離(オプション) | 確定(初版はM/S分離+フィルターの簡易版) |
| チョップ | 確定(7節。一部に仮置きあり) |
| シーケンサー | 確定+仮置き(8節) |

## 3. グローバル設定

| 項目 | 仕様 |
|---|---|
| BPM(グローバル設定) | 画面右上に置く。入力すると、元の音源がそのBPMに変換される。音源未読込時の表示は120。ファイル読み込み時は解析した原曲BPMに合わせ、元の速さで開始する。ユーザーがグローバルBPMを変更するまでは、原曲BPMの手動修正にも追従して原速を維持する |
| 変換方式 | タイムストレッチ(音の高さを変えずテンポだけ変える)。音質の劣化は許容 |
| 適用範囲 | サンプリング、音声分離、チョップ、サンプラー、書き出しの全てが、変換後の音源・BPMで動く |
| シーケンサー側 | BPMを変更できない(グローバル設定の値を使う) |
| BPM変更時 | 音声分離で作った音源は、自動で作り直す |

## 4. サンプリング(確定)

画面は上から次の行で構成する。

| 行 | 内容 |
|---|---|
| 1 | 「サンプリング」の見出し |
| 2 | ファイル選択ボタン、ファイル名の表示(読み取り専用) |
| 3 | 録音ボタン、停止ボタン、録音して保存したファイルのパスの表示 |
| 4 | 原曲再生、範囲試聴、停止、範囲ループ再生(トグル)、削除、元素材のBPM、ズーム、波形 |
| 5 | サンプリング範囲を決める三角マーカー(矢印スライダー)、「範囲を指定してサンプリング」ボタン |

### 4.1 各項目の仕様

- **録音**: 入力元はマイク。録音した音は、読み込んだファイルと同じ扱い(波形表示、範囲指定)にする。保存先のパスを3行目に表示する。
- **元素材のBPM**: 自動解析した値を表示する。手動でも直せる。
- **波形**: ステレオ2ch(L上、R下)で表示する。初期状態では、曲の開始から終了までがぴったり表示される。
- **ズーム**: 波形表示の倍率を変えるスライダー。左端が×1(曲の全体)、右端が最大拡大。拡大すると「左右移動」ツールまたはShift＋ドラッグ、横スクロール、ホイール、スクロールバーで表示範囲を移動でき、範囲を細かく決められる。
- **範囲指定**: 波形本体をドラッグして開始・終了を選ぶ。左右どちらの向きからも選択できる。境界線や上端の2つの三角マーカー(開始・終了)のドラッグ、秒数入力で微調整する。拡大中にマーカーが画面外でも、「始点を指定」「終点を指定」を選んで任意の位置をクリックするか、右クリックメニューの「この位置を始点にする／終点にする」で片側ずつ設定できる。開始・終了の時刻を表示する。通常のクリック再生と左右移動では範囲を動かさない。
- **原曲再生・シーク**: 波形本体をクリックすると、その位置から曲末まで原曲を再生する。選択範囲外の任意の位置からも再生できる。再生位置を表示し、停止後も位置を保持する。「原曲再生」で再開する。
- **範囲試聴・停止・範囲ループ再生**: 「範囲試聴」は指定区間だけを再生する。範囲ループはトグルで、オンにすると範囲試聴時に区間をくり返す。停止の右に置く。原曲再生・試聴・シーク・波形の表示移動は後工程には影響しない。
- **削除**: 読み込んだ音源または録音を破棄する(動作は仮置き。5節)。
- **範囲を指定してサンプリング**: 指定した範囲を確定し、チョップ機能に引き継ぐ。

### 4.2 画面から削った項目

最初の図にあった次の項目は、行ごとの確認で外した。

- 逆再生
- 旧仕様のループ(ループ再生トグルに置き換え)
- 「200M」の表示(ズームの読み違いだった)

## 6. 音声分離(オプション機能・確定)

### 6.1 位置づけ

- 元の音源から、ボーカルとベースを分離して書き出すためのオプション機能。
- チョップ機能への引き継ぎはしない。
- 初版は、M/S分離で取り出したセンタートラック(Mid)に、ハイパスフィルター・ローパスフィルターをかけて取り出す簡易版。
- 後版でAI分離を検討する。その際に、パート名(ドラムなど)を追加する。

### 6.2 画面構成

「音声分離」の見出し(横に「オプション機能」の表示)の下に、パートごとのブロックを置く。ブロックは次の順で構成する。

| パート | 内容 |
|---|---|
| ボーカル | 再生、停止、ハイパスフィルター、ローパスフィルター、書き出し、再生バー |
| ベース | 同じ構成 |

### 6.3 各項目の仕様

- **ハイパス・ローパスフィルター**: パートごとに、ハイパスとローパスを別々に設定する。それぞれに次の3つがある。
  - オンオフスイッチ
  - 勾配の選択スイッチ: -6、-12、-24 dB/oct から選ぶ。デフォルトは-12
  - カットオフ周波数: Hzの数字入力と、スライダーのドラッグの両方で変更できる。両方は連動する
- **再生バー**: 波形、再生位置の線、現在位置と全体の時間、ドラッグできるシークバーを置く。波形のクリックでも、聞きたい位置へ移動できる。
- **書き出し**: そのパートを、フィルター適用後の音でファイルに保存する。
- **音源**: グローバル設定のBPMに変換した後の音源が対象。BPMが変わると、自動で作り直す。
- **実行ボタン**: 設けない。書き出しができればよい。

### 6.4 カットオフ周波数の範囲(確定)と初期値(仮置き)

| 項目 | 範囲(確定) |
|---|---|
| ハイパスフィルター | 50〜2000Hz |
| ローパスフィルター | 200〜8000Hz |

| 項目 | ボーカル | ベース |
|---|---|---|
| ハイパス | オン、200Hz | オフ、200Hz |
| ローパス | オフ、2000Hz | オン、250Hz |
| 勾配 | -12 dB/oct | -12 dB/oct |

初期値とオンオフ状態は、表示用の仮の値(要確認)。カットオフ範囲は訂正済みで、ハイパス50〜2000Hz、ローパス200〜8000Hz。

### 6.5 品質上の注意(判断材料)

- Midは「左右の和」なので、中央に定位した音(ボーカル、ベース、キック、スネアなど)が全て混ざる。フィルターで帯域を切るだけでは、ボーカルとベースを正確には分離できず、他の楽器が混ざる。
- ドラムは、帯域では分離できない。一旦ベースだけにしたのは、この制約とも整合する。
- 精度を上げるには、AI分離(後版)が必要。

## 7. チョップ(確定)

画面は、音声分離の下に置く。

### 7.1 画面構成

| 行 | 内容 |
|---|---|
| 1 | 「チョップ」の見出し |
| 2 | 分割数(2〜8の任意の数)、拍に吸着のオンオフスイッチ |
| 3 | サンプリングした範囲の波形(ステレオ)。分割位置に縦の点線 |
| 4 | 「微調整」の三角マーカーの行。両端の塗りつぶしの三角は、範囲の開始と終了。間の白抜きの三角が、分割位置 |
| 5 | 区間の番号(1〜n)と、区間ごとのループ再生ボタン |

### 7.2 各項目の仕様

- **範囲の受け取り**: 「範囲を指定してサンプリング」で決めた範囲(グローバル設定のBPMに変換後の音源)。
- **分割数**: 2〜8の任意の数を選べる。範囲を等分割する。上限の8は、シーケンサーのトラック数に対応する。
- **区間番号とトラック**: 区間の番号が、そのままトラック番号になる(区間1はトラック1)。分割数がトラック数より少ないときは、残りのトラックは空き。
- **微調整**: 三角マーカーのドラッグ、または矢印キーで、分割位置を動かす。矢印キー1回で1ミリ秒、Shiftキーを併用すると10ミリ秒。
- **拍に吸着**: オンのとき、選択範囲の始点を拍頭として、分割位置をグローバルBPMの8分音符グリッドに揃える。範囲の両端は維持する。オンオフを切り替えられる。
- **再生位置**: ループ試聴中は波形に再生位置の線と区間の強調表示を出し、区間内の経過時間・進行バーを更新する。区間末尾で表示も先頭へ戻る。試聴中に境界を微調整してもループを維持し、新しい区間へ追従する。
- **再生**: 区間ごとのループ再生ボタンだけを置く。同時再生は1つのみ。別の区間を押すと前の区間を停止して切り替え、同じ区間を押すと停止する。シーケンサー開始時には試聴を停止する。

### 7.3 仮置きにしている点(要確認)

| ID | 内容 | 現在の扱い |
|---|---|---|
| C-1 | 拍に吸着の初期状態 | オフ |
| C-2 | 吸着する刻み(1拍単位か、細かい刻みか) | 未決 |
| C-3 | 分割数を変えたときの分割位置 | 等分割の位置に戻す。微調整した位置は失われる |
| C-4 | 複数の区間を同時にループ再生できるか | 不可。同時に1つのみ。別の区間を押すと前の区間を停止 |

## 8. シーケンサー(確定+仮置き)

### 8.1 画面構成

画面は、次の3カラムに分け、罫線で区切る。チョップの下に置く。

| カラム | 内容 |
|---|---|
| 波形 | トラックごとの波形(チョップ区間の音) |
| エディット | 再生、停止、ループ、ピッチ、EQ(HI/MID/LOW)、出力ボリューム |
| シーケンサー | ステップを縦長のバーで表示。ピンクがオンのステップ |

上から順に、次の要素を並べる。

1. 上段の操作: BPM(表示のみ)、再生、停止、先頭へ戻る(⏮)、ループ、書き出し(ステレオ/モノ、WAV/MP3、書き出しボタン)。
2. EQ共通設定(全トラック共通)。
3. 列の見出し(波形/エディット/シーケンサー+ステップ数ボタン)。
4. トラック1〜8。
5. マスターチャンネル。

### 8.2 確定した仕様

| 項目 | 仕様 |
|---|---|
| BPM | グローバル設定の値を表示するだけ。ここでは変更できない |
| ステップ数 | 4・8・16・32のボタンで切り替える。1ステップは8分音符。4・8・16・32ステップは、それぞれ4/8・8/8・16/8・32/8拍子に対応する。BPMは4分音符を基準とし、1ステップの時間は30÷BPM秒、パターン1周はステップ数×30÷BPM秒。サンプルの長さはステップの長さに制限されない。全トラック共通 |
| ステップのバー幅 | スケッチのばらつきに意味はない。幅の指定機能は設けない |
| トラック | 1〜8。区間番号がトラック番号になる。分割数を超えるトラックは空き枠 |
| ミュート/ソロ | トラックごとにM、Sを設ける |
| 発音方式 | シーケンサーは、ステップごとにチョップしたサンプルをトリガーするだけ。ステップの長さには依存せず、サンプルは最後まで鳴る。トラックごとに次の2方式を切り替える。重ねる=次のトリガーで前の音が鳴り続け、重なる。切る=次のトリガーで前の音が途切れ、新しい音に切り替わる。切る対象は同じトラックの音のみ。初期値は「重ねる」(仮置き。8.4節のQ-6) |
| 素材の長さ同期 | トラックごとに「配置に同期」（初期値）・「ステップ数を指定」・「原寸」を切り替える。音程を保って任意長の素材を複数ステップ分へ伸縮し、チョップ試聴・シーケンサー・書き出しに共通の長さを適用する。元音源・範囲・境界は保持。配置からの長さの決定方法は実装仕様に記載 |
| トラック単体の再生・停止・ループ | ピッチとEQの確認用。区間の音のみを鳴らす(パターンは鳴らさない)。再生中のピッチ・EQの変更は、リアルタイムに反映する |
| ピッチ | 機械的な半音単位。±12半音、1半音刻み。調性補正は設けない(旧P-1は解消) |
| ピッチの微調整 | 半音単位のほかに、微調整を設ける(単位・範囲は仮置き。8.3のQ-1) |
| EQ | 3バンド(LOW/MID/HI)。各バンドは、0 dBから-∞のカットのみ。ブーストはなし |
| EQのクロスオーバー | 全トラック共通。LOW|MIDは200〜500Hz、MID|HIは2000〜4000Hz |
| EQの勾配 | 全トラック共通。-6、-12、-24 dB/octから選択 |
| 出力ボリューム | トラックごと。初期値0 dB、範囲は-∞〜+6 dB |
| 書き出し | 全トラックをミックスした1ファイル。パターン1周分。ステレオ/モノ、WAV/MP3を選ぶ |
| BPM横の記号 | スケッチのBPM変更意図は、グローバル設定化により不要 |

### 8.3 マスターチャンネル

全トラックの出力が流れる。マスタートラックは画面下部に固定し、画面のどの位置でも表示・操作できる。

| 項目 | 仕様 |
|---|---|
| インプットレベル | 初期値0 dB、範囲は-∞〜+6 dB。音割れ防止の調整用 |
| ピークメーター | 設ける |

仮置き(要確認): ピークメーターはL/Rの2本。ピークホールド(最大値の保持)と、数値表示(dB)を付ける。0 dBを超えたらクリップ表示を点灯し、ボタンでリセットする。書き出しにも、インプットレベルの設定を反映する。

### 8.4 仮置きにしている点(要確認)

| ID | 内容 | 現在の仮置き |
|---|---|---|
| Q-1 | ピッチの微調整 | ±50セント、1セント刻み。±12半音との合算で最大±12.5半音 |
| Q-2 | ピッチ変更時の長さの扱い | 長さを保つ(時間軸は変えない)。保たない場合は、高くすると短くなる |
| Q-3 | トラックの信号の順序 | ピッチ → EQ → 出力ボリューム → マスター |
| Q-4 | 数値の下限(-∞)の入力 | スライダーの左端が-∞。数値欄は「-∞」または空欄入力で表す |
| Q-5 | マスターのメーターとクリップ表示(8.3の仮置き) | 同左 |
| Q-6 | 発音方式「切る」の細部 | 前の音は即時に切る(短いフェードアウト約5msでクリック音を防ぐ)。初期値は「重ねる」。再生を停止したら、鳴っている音は全て切る |

## 9. 実装方針の案(未承認)

### 9.1 技術

- Web Audio API(ブラウザ)で、再生、フィルター、EQを処理する。リアルタイムに音を変えられる。
- M/S分離は、左右の和(Mid)を計算する。フィルターはバイクアッドフィルターで実現する。
- タイムストレッチは、ライブラリの利用が前提(自前実装は工数が大きい)。選定は、実装の段階で行う。
- 書き出しは、WAVを先に実装し、MP3は後から追加する。

### 9.2 先行例

- Chppr: ブラウザで動く無料のサンプルチョッパー。4トラックのステップシーケンサーとWAV書き出しを備える。
- 差別化できそうな点: 8トラック、トラック別のピッチと3バンドEQ、MP3書き出し、音声分離。
- 参考: https://alternativeto.net/software/chppr/about/

### 9.3 段階(案)

1. 取り込み、波形、ズーム、範囲指定、録音(サンプリング)
2. グローバルBPM(タイムストレッチ)
3. チョップ
4. 1トラックのシーケンサー
5. 8トラック、EQ、ピッチ
6. 書き出し(WAV、次にMP3)
7. 音声分離(オプション)

### 9.4 検証の観点(案)

各段階で、次のような確認基準を決めて検証する。

- 波形: ズーム×1で、曲の全体がぴったり表示される。ズームを上げると、範囲の時刻を細かく指定できる。
- BPM変換: 変換後の長さが、元の長さ×元BPM÷新BPMに一致する(誤差の許容値は別途決める)。
- 範囲: 指定した開始・終了の時刻と、切り出した音の長さが一致する。
- 音声分離: フィルター値を変えると、再生中の音が即座に変わる。書き出したファイルが、再生中の音と同じ内容である。
- 再生バー: 任意の位置へ移動して、その位置から再生される。

## 12. 決定事項ログ

| 項目 | 決定 |
|---|---|
| 録音の入力元 | マイク |
| BPM | グローバル設定。サンプラー側では変更不可 |
| BPM変換方式 | タイムストレッチ。音質の劣化は許容 |
| BPM変更時の分離音源 | 自動で作り直す |
| 試聴(再生・停止・ループ再生) | 試聴専用。後工程には影響しない |
| 範囲確定 | 範囲を確定して切り出し、チョップに引き継ぐ |
| 音声分離 | オプション機能。ボーカルとベース。書き出しのみ。チョップへは引き継がない |
| 音声分離の初版方式 | M/S分離のセンタートラック+ハイパス・ローパスフィルター |
| ドラム | 一旦なし。AI分離の版で、パート名を追加する |
| ズーム | 左端が×1、右端が最大拡大 |
| ピッチの調性補正 | 難しければ初版では削ってよい |
| フィルターのオンオフ | ハイパス・ローパスのそれぞれに、オンオフスイッチを設ける |
| フィルターの勾配 | -6、-12、-24 dB/oct から選択。デフォルトは-12 |
| ハイパスのカットオフ範囲 | 50〜2000Hz |
| ローパスのカットオフ範囲 | 200〜8000Hz |
| チョップの分割数 | 2〜8の任意の数(等分割) |
| 区間とトラック | 区間の番号がそのままトラック番号 |
| チョップの再生 | 区間ごとのループ再生ボタンのみ(停止中に押すと再生、再生中に押すと停止) |
| 分割位置の微調整 | ドラッグと矢印キー。矢印キー1回で1ミリ秒、Shift併用で10ミリ秒 |
| 拍に吸着 | オンオフを切り替えられる |
| チョップ画面の位置 | 音声分離の下 |
| シーケンサーのステップ数 | 4・8・16・32のボタン。全トラック共通。1ステップは8分音符で、それぞれ4/8・8/8・16/8・32/8拍子に対応。サンプルの長さは任意 |
| ステップのバー幅 | 意味なし。幅指定は設けない |
| トラック単体の再生 | ピッチとEQの確認用。区間の音のみ |
| 書き出し | 全トラックのミックス1ファイル。パターン1周分 |
| ピッチ | ±12半音の機械的な変更+微調整。調性補正なし |
| EQ | 3バンド。0〜-∞のカットのみ。クロスオーバー(LOW|MID 200〜500Hz、MID|HI 2000〜4000Hz)と勾配(-6/-12/-24)は全トラック共通 |
| トラックの出力ボリューム | 初期値0 dB、-∞〜+6 dB |
| マスターチャンネル | 全出力が流れる。インプットレベル(初期値0 dB、-∞〜+6 dB)とピークメーターを設ける |
| プロジェクト保存（2026-10-28、#2） | 音源と設定を `.fflab` ファイルに保存・読み込みする。ブラウザ内に1件だけ自動保存し、起動時に復元を選べる |
| シーケンサーの発音方式 | ステップはサンプルをトリガーするだけ。トラックごとに「重ねる」(重なって鳴る)/「切る」(次の音で前の音が途切れる)を切り替える |
